# بنك أسئلة QuizBattle العربي

هذا بنك أسئلة داخلي مستقل بصيغة JSON Lines، صيغت أسئلته وشروحه بالعربية خصيصًا للمشروع. لا يحتوي على نسخة من بنك أسئلة تجاري أو محمي. الإصدار الحالي يضم **1573 سؤالًا نشطًا**، وكل سؤال له مصدر وأثر تحقق و`contentHash` مستقل.

## الملفات

- `questions.ar.jsonl`: البنك القابل للاستيراد، سؤال واحد في كل سطر UTF-8.
- `question.schema.json`: عقد JSON Schema المطابق لنموذج السؤال الجديد.
- `manifest.json`: العدد، التقسيم، وبصمة SHA-256 للملف الكامل.
- `validation-report.json`: نتيجة التحقق، التكرارات، وتوزيع الإجابات.
- `SOURCES.md`: المصادر، الترخيص/الإسناد، وحدود الاستخدام.
- `../../tools/question-bank/generate.py`: مولد حتمي يعمل دون شبكة.
- `../../tools/question-bank/validate.py`: مدقق البنية والمحتوى الأساسي.
- `../../tools/question-bank/test_question_bank.py`: اختبارات الانحدار والحتمية.

## عقد السؤال

كل سطر يطابق الحقول التالية فقط:

```json
{
  "id": "qb-science-element-symbol-0001",
  "category": "science",
  "difficulty": "easy",
  "prompt": "ما الرمز الكيميائي لعنصر الهيدروجين؟",
  "options": ["H", "He", "Li", "Be"],
  "correctOptionIndex": 0,
  "explanation": "الرمز المعتمد لعنصر الهيدروجين هو H، وعدده الذري 1.",
  "source": {
    "type": "primary-reference",
    "title": "IUPAC Periodic Table of the Elements (4 May 2022)",
    "url": "https://iupac.org/wp-content/uploads/2022/07/IUPAC_Periodic_Table-04May22_CRA.pdf",
    "license": "Facts referenced from IUPAC; question wording is original"
  },
  "verifiedAt": "2026-08-15T00:00:00Z",
  "language": "ar",
  "status": "active",
  "contentHash": "...64 lowercase hex characters..."
}
```

`correctOptionIndex` يبدأ من الصفر، ويجب ألا يخرج إلى العميل قبل أن يرسل الخادم إجابة اللاعب. تحسب `contentHash` من تمثيل JSON حتمي لكل الحقول عدا الحقل نفسه، بما يسمح باكتشاف التعديل أو الاستيراد المتكرر.

## إعادة البناء والتحقق

من جذر المستودع، باستخدام Python 3.10 أو أحدث:

```powershell
python tools/question-bank/generate.py
python tools/question-bank/validate.py
python -m unittest discover -s tools/question-bank -p "test_*.py" -v
```

المولد حتمي: تشغيله مرتين على المصدر نفسه ينتج البايتات والبصمة نفسيهما. المدقق يفشل عند وجود:

- أقل من 1000 سؤال أو انخفاض أي مجال عن الحد الأدنى المحدد.
- معرف أو نص سؤال مكرر بعد تسوية الحروف العربية والتشكيل.
- خيارات ليست أربعة وفريدة، أو مؤشر إجابة خارج المدى.
- حقول زائدة/ناقصة، تاريخ ليس RFC3339، أو `contentHash` غير صحيح.
- مصدر بلا عنوان/رابط/بيان ترخيص، أو نص سياسي يعتمد على شاغل منصب حالي.
- محتوى غير عربي في السؤال أو الشرح.

## ملاحظات تحريرية

- أسئلة الرياضيات مولدة أصليًا، مع نتائج وشروح محسوبة؛ مصدرها `urn:quizbattle:generator:mathematics-v1`.
- أسئلة الدين محصورة في أسماء السور وترتيبها. لا توجد فتاوى أو اقتباسات آيات أو مسائل خلافية. يوصى مع ذلك بمراجعة مختص قبل النشر العام.
- لا توجد أسئلة عن الرؤساء أو الملوك أو الوزراء الحاليين، ولا عن نتائج انتخابات أو أرقام سريعة التغير.
- حالات العواصم الملتبسة أو الانتقالية استبعدت قدر الإمكان. ينبغي إعادة التحقق التحريري الدوري قبل إصدار موسمي جديد.
- التحقق الآلي يثبت سلامة العقد والحسابات والتكرار والبصمات؛ لا يغني عن مراجعة بشرية دورية لعينة ممثلة من الحقائق والترجمة العربية.

## الاستيراد الآمن

ينبغي أن يقرأ المستورد الملف سطرًا بسطر، ويتحقق من `contentHash` والعقد، ثم ينفذ upsert باستخدام `id`. لا تُستبدل الأسئلة المنشورة تلقائيًا عند تغير البصمة؛ الأفضل إنشاء سجل مراجعة وإيقاف السؤال القديم أو إصدار نسخة جديدة. لا تستورد الإجابة الصحيحة إلى أي نموذج يرسله API إلى المتصفح.
